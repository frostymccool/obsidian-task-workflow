# Changelog

All notable changes to this package are documented here.

## 1.0.0 — 2026-10-06

- Portable installer for Tasks, Task Status, the Task Workflow Sorter, and the CSS snippet.
- Nine distinct task states with a compact, labelled right-click/long-press picker.
- Deferred tasks automatically move to the bottom of their current Markdown list.
- Harness-neutral `SKILL.md`, explicit default-vault safeguard, and backup-aware configuration updates.
